# MakerShelf starter site

A zero-cost static affiliate site starter for GitHub Pages.

## Before publishing
1. Replace every `YOUR_EVERBEE_AFFILIATE_LINK` with your EverBee affiliate URL.
2. Replace every `YOUR_ERANK_AFFILIATE_LINK` with your eRank affiliate URL.
3. Replace `/makershelf-starter/` in navigation links with your GitHub repository name if you use a different repo name.
4. Keep the affiliate disclosure visible.
5. Re-check product pricing/features before major article updates.

## Free publishing with GitHub Pages
1. Create a new public GitHub repository, e.g. `makershelf-starter`.
2. Upload all files in this folder.
3. Open Settings → Pages.
4. Under Build and deployment, choose "Deploy from a branch".
5. Select `main` and `/ (root)`, then Save.
6. Your site will appear at `https://YOURUSERNAME.github.io/makershelf-starter/`.
